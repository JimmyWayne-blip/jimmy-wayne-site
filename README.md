# Jimmy Wayne — Race Mentorship

Next.js site for jimmywayne.run.

## Run locally

```bash
npm install
npm run dev
```

## Deploy

Import this project into Vercel. Vercel detects Next.js automatically. Add `jimmywayne.run` under Project Settings → Domains, then configure the DNS records shown by Vercel at your domain registrar.

## Before launch

- Replace placeholder photography with Jimmy's own race/mountain photography.
- Add the final Calendly booking URL.
- Connect Stripe/Calendly payment flow.
- Review race-page copy and personal bio.
- Add social/contact links.
